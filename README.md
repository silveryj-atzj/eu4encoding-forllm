## English

Encoding converter for Europa Universalis IV 1.37.5: converts garbled mod text to and from Chinese, designed for large-scale batch processing with LLMs.

Developed with LLMs on top of the Chinese localization patch — I only wrote the prompts, hehe.

Thanks to [matanki-saito/EU4dll](https://github.com/matanki-saito/EU4dll) for the double-byte patch.
